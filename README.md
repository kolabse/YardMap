# YardMap

«ПланДач» — редактор планировки дачного участка. Прямоугольный участок,
каталог построек, перенос объектов и предварительные подсказки расстояний.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8765`. Сборка и установка зависимостей не требуются.

После создания участка добавьте постройки и перетащите их из области
«Неразмещённые объекты» на план. Полностью вынесенный за участок объект
возвращается в эту область. Изменение размера участка сохраняет реальные
размеры и координаты объектов. Пока данные существуют только в памяти страницы.

Размеры участка и построек вводятся в метрах; допускаются дробные значения.
Ошибки показываются рядом с полями, не меняя текущий план. После создания
участка кнопка «Изменить размеры» обновляет его, сохраняя объекты. Постройки,
оказавшиеся за границами после уменьшения участка, отмечаются красной пунктирной
рамкой и предупреждением. Кнопка «Новый проект» открывает подтверждение очистки
объектов и границ; новый участок получает размеры из полей формы.

«Проверка размещения» оценивает весь план независимо от выделения: выходы
за участок, перекрытие контуров и отступы меньше заданных. Касание считается
отдельно; оно допускается для пары с порогом 0 м, но перекрытие остаётся ошибкой.
Неразмещённые объекты исключены из проверки. Линии между объектами соединяют
ближайшие точки контуров; для перекрытия вместо допустимого нулевого расстояния
показывается ошибка. Пороги — предварительные значения прототипа, а не
подтверждённые нормативы.

## Структура

- `js/catalog.js` — типы объектов и подписи границ.
- `js/model.js` — данные проекта и операции над ними; без DOM и пикселей.
- `js/geometry.js` — геометрия в метрах и преобразование координат отображения.
- `js/rules.js` — прежние пороги расстояний; их источники ещё не проверены.
- `js/placement.js` — независимая проверка всего размещённого плана.
- `js/renderer.js` — HTML-отрисовка и измерительные линии.
- `script.js` — формы и обработка переноса; состояние интерфейса отдельно от проекта.

Координаты размещённых объектов отсчитываются от северо-западного угла участка:
`x` направлена на восток, `y` — на юг. Размеры и координаты хранятся в метрах.
У неразмещённых объектов статус `waiting` и координаты `null`.
Отрисовщик хранит ссылки на элементы отдельно, по стабильным ID объектов.

HTML-отрисовка сохранена для первого этапа. Возможный переход на SVG относится
к управлению видом (YM-009) и не меняет контракт модели.

## Проверки

Нужен Node.js с поддержкой встроенного `node:test` (Node.js 18 или новее).

```sh
node --test tests/*.test.js
```

Проверяются модель, геометрия и сценарии редактора с небольшим тестовым DOM.
Тестовый DOM не проверяет реальную CSS-разметку; перенос и масштаб дополнительно
проверяются в браузере.
