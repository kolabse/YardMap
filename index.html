Планирование участка в СНТ

Ctrl/Cmd+Z — отменить, Ctrl/Cmd+Shift+Z или Ctrl+Y — повторить. В полях ввода сочетания редактируют текст.

Удаление нельзя отменить. Перед удалением можно скачать JSON этого варианта кнопкой ниже.

Сохранённую запись не удалось открыть. Заменить её текущим планом? Прежняя запись будет перезаписана. Текущий план можно предварительно скачать в JSON.

Открытие заменит активный вариант. Другие варианты сохранятся. Перед заменой можно скачать JSON активного варианта.

Размер участка

Новый проект очистит активный вариант; остальные варианты сохранятся. Перед заменой можно скачать его JSON. Размеры нового участка задайте в полях выше.

Добавление построек

Проверка размещения

    Отступы — предварительные настройки. Их источники и применимость ещё не проверены. Касание допустимо только при заданном отступе 0 м; перекрытие контуров считается ошибкой.

    Неразмещённые объекты

    Перетащите объект на участок. Объекты в этой области не участвуют в проверке расстояний.

    Легенда построек

    Кликните на тип постройки для выделения

    Предварительные настройки расстояний

    Значения из прототипа используются для сравнения вариантов планировки. Они ещё не проверены по действующим документам и не подтверждают соответствие требованиям.

    • До каждой границы участка задано: для дома — 3 м, туалета и колодца — 8 м, остальных объектов — 1 м.
    • Заданные отступы между объектами показаны на измерительных линиях выбранной постройки.
    • Для парковки задан отступ 0 м до других объектов: касание допускается, перекрытие — нет.
