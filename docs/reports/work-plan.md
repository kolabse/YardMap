# План развития YardMap / «ПланДач»

Дата составления: 2026-10-02. Основание: изучение текущего прототипа и обсуждение порядка изменений с пользователем.

Цель: сделать редактор, в котором можно точно разместить объекты дачного участка, сохранить варианты планировки и получить объяснимые предупреждения о размещении.

## Правила ведения плана

- Канонический план: `docs/reports/work-plan.md`. Журнал результатов при выполнении задач: `docs/reports/work-log.md`.
- Код проекта: YardMap. Префикс задач: `YM`. Это первый план; прежних реестров задач и журнала в проекте не обнаружено. Выделены ID `YM-001`–`YM-015`; ID не переиспользуются.
- Статусы: `planned` — запланировано; `in_progress` — выполняется; `blocked` — есть описанное препятствие; `awaiting_verification` — реализация ожидает проверки.
- Порядок этапов согласован в обсуждении. Даты выполнения не назначены. Часовой пояс для будущих дат: `Asia/Yekaterinburg`.
- Задача завершена, когда выполнены её критерии готовности, проверены соответствующие сценарии и результат записан в журнал с ID задачи. Затем задача переносится из активной очереди в историю.
- Реализация начата: завершены YM-001–YM-012. Результаты и проверки записаны в журнале.

## Этап 5. Новые объекты и формы участка

Результат этапа: редактор поддерживает реальную планировку сада и полезен при обсуждении проекта вне приложения.

### YM-013 — Расширить каталог объектов и показатели площади

- Добавить грядки, теплицу, деревья, дорожки, ворота, септик и коммуникации, распределив их по понятным категориям.
- Ввести необходимые геометрические типы: площадь, точка/круг и линия. Для дерева различать положение ствола и проекцию кроны.
- Показывать площадь участка в м² и сотках, площадь зон и долю занятой территории с явно описанной методикой.

Критерии готовности: новые типы сохраняются, редактируются и участвуют в истории; проверки учитывают назначение объектов, например разрешённое наложение линии коммуникаций на территорию; итоговая занятая площадь не удваивает пересекающиеся зоны.

### YM-014 — Добавить участки произвольной формы

- Поддержать создание и редактирование многоугольного контура с длинами сторон.
- Отклонять вырожденные и самопересекающиеся контуры; корректно рассчитывать площадь, попадание объектов внутрь и расстояния до сторон.
- Хранить соседство и ограничения по отдельным сторонам контура; обновить формат проекта с поддержкой прямоугольных проектов предыдущей версии.

Критерии готовности: проверены прямоугольный, трапециевидный и вогнутый участки; объект, пересекающий выемку вогнутого контура, определяется как выходящий за границу; изменение вершины обновляет площадь и проверки; старые проекты открываются.

### YM-015 — Добавить подложку и экспорт плана для печати

- Добавить локальную подложку из изображения с калибровкой по известному расстоянию, настройкой прозрачности и фиксацией положения.
- Определить хранение подложки и переносимость проекта с ней; предусмотреть понятную обработку отсутствующего изображения.
- Экспортировать план в SVG/PNG и подготовить печатное представление с размерами, легендой, названием проекта и масштабной линейкой.

Критерии готовности: калибровка не меняет геометрию объектов; состояние подложки восстанавливается по описанному контракту; экспорт соответствует текущему плану и читается без интерфейсных панелей; размеры бумаги и масштаб печати указаны явно.

## Проверка и границы объёма

- Для геометрии и формата проекта нужны автоматические проверки граничных случаев; для взаимодействий — проверка основных пользовательских сценариев в браузере.
- После каждого этапа проходить цепочку: создать участок → добавить объекты → изменить план → проверить предупреждения; после этапа 2 также сохранить и восстановить.
- После введения истории проверять сценарии отмены, повтора и сохранения итогового состояния.
- Сервер, учётные записи, совместное редактирование, 3D и моделирование теней не входят в текущую очередь. Они требуют отдельного решения после получения устойчивого редактора.
